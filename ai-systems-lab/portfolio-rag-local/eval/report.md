# Portfolio RAG Evaluation Report

This file is generated by:

```powershell
python eval/run_eval.py
```

Use retrieval-only mode first. After the index works and `GEMINI_API_KEY` is configured, run:

```powershell
python eval/run_eval.py --with-llm
```

The report checks whether retrieval finds the right source chunks and, in LLM mode, whether answers include or avoid important phrases.
